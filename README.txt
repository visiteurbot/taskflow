TaskFlow - 個人用タスク管理

■ 起動方法
  TaskFlow.bat をダブルクリックします。
  Edge（なければ Chrome、それもなければ既定のブラウザ）で開きます。
  index.html を直接ダブルクリックしても使えます。

■ データについて
  タスクはお使いのブラウザの中（localStorage）に保存されます。外部には送信されません。
  ・ブラウザの履歴・サイトデータを消すとタスクも消えます。
  ・いつも同じブラウザ（Edge など）で開いてください。ブラウザを変えるとデータは別扱いになります。
  ・左下の ⬇ でバックアップ（JSON）、⬆ で読み込み、🗑 で全削除ができます。

■ 使い方
  上の入力欄に「見積書を送る 明日 !高 #営業」のように書いて Enter。
  毎日 / 毎週月曜 / 毎月25日 と書くとくり返しタスクになります。!重要 と書くと「今日」に常に表示されます。
  ショートカット: / 入力欄  N 新規(詳細)  1〜6 画面切替  Ctrl+F 検索
