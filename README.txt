TaskFlow - 個人用タスク管理

■ 起動方法
  TaskFlow.bat をダブルクリックします。
  Google Chrome（なければ Edge、それもなければ既定のブラウザ）で開きます。
  index.html を直接ダブルクリックしても使えます。

■ データについて
  タスクはお使いのブラウザの中（localStorage）に保存されます。外部には送信されません。
  ・ブラウザの履歴・サイトデータを消すとタスクも消えます。
  ・いつも同じブラウザ（Chrome など）で開いてください。ブラウザを変えるとデータは別扱いになります。
  ・左下の ⬇ でバックアップ（JSON）、⬆ で読み込み、🗑 で全削除ができます。

■ 使い方
  上の入力欄に「シミュレーション実施 金曜 !高 #信頼性」のように書いて Enter。
  毎日 / 毎週月曜 / 毎月25日 と書くとくり返しタスクになります。!重要 と書くと「今日」に常に表示されます。
  @プロジェクト名 と書くと、そのプロジェクトのタスクになります。
  ショートカット: / 入力欄  N 新規(詳細)  1〜9 画面切替  Ctrl+F 検索

■ リンクタブでフォルダ／ファイルを開く（任意・初回のみ）
  setup-folder-open.bat を一度ダブルクリックすると、リンクに登録したフォルダやファイルの
  パス（C:\... や \server\...）をクリックしたとき、エクスプローラーで開けるようになります。
  ・初回クリック時に Chrome が許可を求めます。「常に許可」にして「開く」を押してください。
  ・このフォルダを移動した場合は、もう一度 setup-folder-open.bat を実行してください。
  ・元に戻すときは remove-folder-open.bat を実行します。
  ・安全のため、プログラム/スクリプト（.exe .bat .ps1 など）は開きません。

■ 画面の構成
  個人タスク: 今日 / 近日 / すべて / カレンダー / あとで / 週報
  プロジェクト: プロジェクトごとのマイルストン・重要会議・タスクを一元管理（全体のタイムライン表示つき）
  ノート: メモ（アイデアの置き場）/ リンク集

■ 更新するときは
  1. 左下の ⬇ でバックアップを書き出す
  2. 新しい zip を展開して、フォルダに上書きする
  3. 開いてデータが残っているか確認（空なら ⬆ でバックアップを読み込む）

■ 自動バックアップ（任意・おすすめ）
  左下の 💾 から、バックアップを自動保存するフォルダを選びます（OneDrive・共有フォルダなど、PCが壊れても残る場所）。
  データを変更するたびに、taskflow-backup-latest.json と、日付つきファイル（直近30日分）が保存されます。
  ・Chrome / Edge で使えます。ブラウザを開き直したときは、💾 から「許可して再開」が必要なことがあります。
  ・復元するときは、左下の ⬆ でバックアップファイルを読み込みます。

■ 週報
  週ごとに、完了したタスク・会議・プロジェクト進捗（マイルストンの残り日数）・先週比を自動でまとめます。
  編集して「保存」すると過去の週報として残り、一覧からいつでも開けます。
